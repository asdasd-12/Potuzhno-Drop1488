# Potuzhno Drop Telegram Bot

Python Telegram collection game bot.

## Features
- Fictional collectible vans and drones
- Virtual coins and daily reward
- Case opening, inventory, upgrade attempts and leaderboard
- SQLite storage

All items and coins are fictional and have no real-money value.

## Deploy on Render
Create a **Background Worker** from this repository.
- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- Add environment variable `BOT_TOKEN` with the token from @BotFather.

Never commit your bot token to GitHub.
